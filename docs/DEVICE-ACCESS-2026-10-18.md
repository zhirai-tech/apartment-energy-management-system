## 2. 统一「添加设备」向导（新增）

入口：**系统设置 → 设备总览 → 右上角「＋ 添加设备」**（也复用于其他页面）。

三种添加方式：

### 2.1 局域网扫描（自动发现 + 识别）

1. 自动检测网段（或手动填 `192.168.41.0/24`）→ **开始扫描**；
2. 扫描结果表格：IP / MAC / 厂商 / **设备类型（自动识别）** / 状态；
3. 可点 **「端口/能力探测」** 对设备做进一步探测（只读）：
   - **开放端口**（80/443/22/554/2020/8000/502/6668/9100/54321…）
   - **HTTP 页面标题 / Server 头**（用于识别华为 EMUI、Apache 等）
   - **MiIO 本地协议**（UDP 54321 握手）→ 识别"小米设备，支持本地控制"
   - **设备类型推断**：网络摄像头 / 路由器 / 小米空开或智能设备 / 打印机 / NAS / 电脑 / IoT
4. 勾选设备 → **添加选中**（按识别到的分类入库，可后续在设备总览里改房间/改名）。

> 实测（本机所在局域网）：扫描 38 台设备、Ping 在线 28 台；识别出：
> - **10 台小米智能设备（UDP 54321 可本地接入，.181~.190）**
> - 水星摄像头（端口 80/554/2020）
> - Nokia Beacon 节点（80/443/22/5000，识别为路由器/WiFi 网关）
> - 电脑/服务器若干

## 12. 米家空开「本地化」完成：断外网也能读数和控制（2026-10-18 深夜）

### 12.1 云登录（一次性）

- 主账号 xiaomi-account@example.com + 相机区账号的密码 → 小米要求邮箱验证码；
- 邮箱验证码校验通过，**米家云登录成功**（国内区），同步到 10 台设备；
- 用适配器拉取设备本地 token（32 位），通过系统设置页 **「同步空开本地 Token」** 写入每台设备的局域网控制配置。

### 12.2 本地 miIO 协议（10 台真机实测）

| 项 | 值 |
|---|---|
| 协议 | miIO（UDP 54321） |
| 握手 | 21 31 00 20 + 28×0xFF，设备返回 deviceId/stamp |
| 加密 | AES-128-CBC，key=md5(token)，iv=md5(key+token)[0:16]，checksum=md5(header+token+encrypted) |
| 该批设备命令 | **get_properties / set_properties**（标准 miotspec/prop/get 会返回 -9999 undefined command） |
| 属性 | siid2.piid1=开关(bool)；siid2.piid6=温度；siid3.piid1=累计电量(0.01 kWh)；siid3.piid2=电流(mA)；siid3.piid3=电压(0.1V)；siid3.piid6=功率(W) |

### 12.3 实测结果

- **10 台空开全部本地读取成功**，且与小米云数值一致（例：L16 云端 129.48 kWh / 本地 129.53 kWh；电压 229.8V / 230.3V）；
- 后端每 **10 秒**通过局域网直连轮询一次，写入：功率、电流、电压、累计电量、在线状态、同步时间；
- 控制链路已切换为**本地优先**：POST /system/device/:did/control 返回 mode: "local"，set_properties 写入成功（测试用相同值写入，未实际断电）；
- 云 token 只需获取一次；之后即使断外网，读数和开关控制都能正常工作（局域网内）。
- 重新登录米家云后，在「设备接入 → 米家云」点 **「同步空开本地 Token」** 即可刷新 token。
