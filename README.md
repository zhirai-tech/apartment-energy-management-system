# ZAEM Apartment Energy Manager

A centralized electricity management platform for apartments, dormitories, rentals and multi-room buildings. It connects Xiaomi/Mi Home power-control devices and covers live power, daily usage, history, alerts, manual cut-off and automatic restore.
